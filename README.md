# FieldManual369

**The Interactive Field Manual for Building Intelligent Systems**

Learn the concept. Test the claim. Build the system. Verify the result.

FieldManual369 is a freely accessible, independently authored learning environment for agent architecture, UX, product strategy, evidence assessment, information architecture, systems thinking, governance, research design, cybersecurity, and data modeling.

This repository is being initialized with a React/TypeScript learning application, a practical evidence lab, locally saved progress, and an automated GitHub Pages workflow.

## Principles

- Original educational content and implementation. Reference illustrations are inspiration, not copied assets.
- Separate signals, interpretations, and conclusions; surface assumptions and sources.
- No unreviewed external actions, secrets, or connected-system access.
- Mobile-friendly, keyboard-accessible, useful offline, and approachable for beginners.
- Favor completion evidence and tests over claims of completion.
