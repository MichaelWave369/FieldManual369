# Poster assets

Poster metadata and reader are part of the v0.2 source-code pull request. The 21 binary images must be placed in this folder separately.

1. Download and extract `FieldManual369_PR2_Poster_Assets.zip` from the PR conversation.
2. Copy all 21 `.webp` files from its `public/posters/` directory here on the PR branch.
3. Commit those files to the branch and rerun CI. Then open the gallery and validate images at full zoom.

The asset archive includes original poster filename mappings and SHA-256 checksums under `docs/archive/`. The original archive is not modified.

**Rights boundary:** The source code MIT license does not automatically grant third-party or underlying-reference rights in images. Posters are included only at the uploader's direction and should be reviewed for quality and suitability before public release.
